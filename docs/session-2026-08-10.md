# Sesi Kerja — Otomatis Screening Job (10 Agustus 2026)

Ringkasan percakapan & pekerjaan sesi ini. Tujuan: menyelesaikan program
`freelance-lead-gen` agar bisa otomatis screening job dari discovery sampai
draft siap kirim.

## Hasil Akhir (terverifikasi dengan pipeline nyata)

Pipeline berjalan end-to-end:

```
discovery → filtering/screening → personalisation → verification → HITL
```

Run nyata dengan RemoteOK (100 lead):

- 100 lead ditemukan (~3 detik, tanpa browser)
- 95 ditolak saat screening, 5 qualified
- 4 draft terverifikasi, sisanya menunggu review HITL

LLM screening (Groq `llama-3.3-70b-versatile`) berfungsi: menolak entri yang
bukan lowongan (artikel motivasi seperti "Stay Hungry. Stay Foolish...",
"No Open Roles", deskripsi tidak jelas) dan mengkualifikasi lowongan asli.

## Perbaikan Inti

1. **`pipeline` command sekarang men-discover otomatis**
   - Sebelumnya `LeadGenOrchestrator` tidak pernah membuat `DiscoveryAgent`
     (default `None`), jadi fase discovery selalu di-skip.
   - Fix: buat `DiscoveryAgent(settings=...)` di `orchestrator.initialize()`
     jika belum ada (`agents/orchestrator.py:526`), import runtime dipindah ke
     atas (bukan `TYPE_CHECKING`).

2. **Fallback `json_schema` → `json_object` untuk Groq**
   - Model `llama-3.3-70b-versatile` tidak mendukung `response_format:
     json_schema` (error 400).
   - Fix: di `LLMClient.complete()`, saat API menolak format tersebut, retry
     sekali dengan mode `json_object` dan parse schema Pydantic yang sama
     (`llm/client.py`).

3. **Rate limiter berbasis TPM (token per menit)**
   - Rate limiter lama hanya menghitung jumlah request (RPM), sehingga burst
     token melampaui TPM Groq free tier (12.000) → 429.
   - Fix: `SlidingWindowLimiter` baru di `llm/rate_limiter.py` — window
     berjalan 60 detik, admit request bila jumlah reserve (input + estimasi
     output) dalam window ≤ budget; lalu `settle()` mengganti estimasi dengan
     usage aktual setelah respons; `cancel()` menghapus reserve saat gagal
     (termasuk `asyncio.CancelledError`).
   - Setting baru: `LLM_MAX_TOKENS_PER_MINUTE` (default 10.000) dan
     `LLM_ESTIMATED_OUTPUT_TOKENS` (default 2.048).

4. **Bug double counting skor screening**
   - Sebelumnya `FilteringReport.low` menggandakan jumlah (input=5 → low=10)
     karena perhitungan di loop LLM + loop tally tambahan.
   - Fix: hapus loop tally akhir; hitung `high/potential/low` langsung di
     titik penentuan tier (`agents/filtering_agent.py`).

5. **Fix mojibake UTF-8 dari API RemoteOK**
   - API RemoteOK mengirim teks double-encoded UTF-8-as-Latin-1 (`â€™` untuk
     `’`), termasuk emoji terpotong.
   - Fix: helper `_fix_mojibake()` di `discovery/platforms/job_boards.py` —
     deteksi karakter kontrol C1 (U+0080–U+009F) lalu round-trip
     `encode('latin-1') → decode('utf-8')`. Terapkan pada title/company/
     description di RemoteOK & YC Work.

6. **Optimasi discovery**
   - Flag `requires_browser` (default `True`): RemoteOK & YC Work override ke
     `False`, jadi browser tidak perlu di-start bila hanya platform HTTP yang
     aktif (70 detik → ~3 detik).
   - Flag `query_agnostic`: platform yang API-nya mengembalikan seluruh daftar
     lowongan terlepas dari query hanya di-fetch sekali per cycle, bukan per
     query (mencegah duplikasi 4x untuk 4 query).

7. **Truncate deskripsi untuk input LLM**
   - Deskripsi bisa mencapai 22k karakter; kirim penuh ke LLM memboroskan
     token. Fix: potong 3000 karakter di `_build_classification_input`
     (filtering) dan `_build_draft_context` (personalisation).

## Catatan & Batasan

- **Kuota harian Groq free tier (100k TPD) habis** akibat banyak testing
  (`Rate limit reached ... tokens per day`). Solusi: tunggu reset, upgrade ke
  Dev Tier, atau ganti provider via `.env`
  (`LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` — OpenAI-compatible).
- **YC Work** masih bermasalah (API diblokir 406, halaman SPA timeout) —
  dipertahankan sebagai platform aktif tapi men-degrade gracefully (0 lead).
- **Upwork / LinkedIn** memerlukan browser + kredensial/sesi tersimpan.
- Mojibake emoji terpotong di sumber API tidak bisa diperbaiki (1 dari 100
  judul) — bukan masalah di sisi parser.

## Cara Menjalankan

```powershell
$env:PYTHONIOENCODING="utf-8"
.venv\Scripts\python.exe -m freelance_lead_gen pipeline          # penuh: discover → screening → draft
.venv\Scripts\python.exe -m freelance_lead_gen discover          # hanya discovery
.venv\Scripts\python.exe -m freelance_lead_gen list              # lihat leads
.venv\Scripts\python.exe -m freelance_lead_gen review            # review draft HITL
```
